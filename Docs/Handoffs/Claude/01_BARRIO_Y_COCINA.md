# Encargo artístico 01 — Barrio residencial y cocina

**Destinatario:** Claude, dirección artística. **Estado:** preparado; no enviado ni aprobado.

Diseña una identidad visual original para el primer barrio de una ciudad costera mexicana ficticia y la casa donde el protagonista vende hamburguesas. Tono de comedia y ambición empresarial, con calidez diurna y proporciones caricaturescas creíbles. La primera escena debe poder leerse desde la cámara en primera persona.

## Entregables solicitados

1. Tablero de referencias de ambiente, siluetas y paleta con fuentes/licencias identificadas.
2. Plano acotado de una casa pequeña, entrada, cocina, puesto y recorrido del cliente.
3. Hojas de diseño para mostrador, caja de ingredientes, parrilla y señalética; tres objetos deben distinguirse a 2–3 m.
4. Especificación de materiales, iluminación y presupuesto aproximado de polígonos/texturas para PC media.
5. Propuesta de HUD de dinero, pedido e interacción para teclado/ratón, con jerarquía y estados.
6. Lista de modelos y animaciones priorizados para el siguiente hito.

El prototipo actual usa geometría y UI provisionales. No copiar recursos de Schedule I ni diseñar todavía el Casino FOX completo. Presentar decisiones visuales revisables antes de sustituir los elementos provisionales.
